# Jarvis

Assistente pessoal e agente para projetos, baseado em Hermes Agent, com funcionamento essencial sem API paga obrigatória.

## Retomada
Leia AGENTS.md e docs/ESTADO.md. Consulte docs/PLANO.md apenas para decisões de escopo e docs/INSTALACAO.md para procedimentos técnicos. O código original do Hermes permanece separado; este repositório guarda nossas extensões, scripts e documentação.

## Estado
Base Hermes e modelo local funcionando. Iniciador validado em execução não interativa: carrega o motor, executa tarefa e encerra o servidor. Hermes criou arquivo e um site HTML local. Aplicativo desktop compilado e iniciado; conversa pela janela, qualidade ampla e integrações ainda em validação. Veja docs/USO.md. Não enviar modelos, executáveis, logs, ambientes ou credenciais para GitHub.
